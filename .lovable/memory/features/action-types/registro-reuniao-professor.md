Rótulo "Reunião com o Professor"; título automático. Cadastro: Consultor, Escola, Data, Professor (texto, `programacoes.apoio_professor_nome`).
Formulário (`ReuniaoProfessorContent.tsx`): 1. `foco` múltiplo (12 opções + Outros→`foco_outros`), 2. `tema_reuniao`, 3. `participacao_professor` (Descompromissada…Compromissada), 4. `encaminhamentos` Sim/Não, 5. `anotacoes` opcional. Só 5 é opcional.
Painel `/relatorios-reuniao-professor` (N1, N2/N3 Escolas) e cartão em Relatórios de Gestão - Programa Escolas.
